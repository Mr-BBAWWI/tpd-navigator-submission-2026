# TPD Navigator 공개 연구 비교실

이 디렉터리는 저장된 연구 기록을 조회하는 정적 공개본입니다. `index.html`을 직접 열거나, 필요하면 이 디렉터리에서 `python -m http.server`로 로컬 정적 서버를 열 수 있습니다. 자격 증명이나 외부 서비스는 필요하지 않습니다.

- 새 LLM 또는 GPU 계산을 실행하지 않습니다.
- 과학적 승인과 인간 전문가 승인은 모두 false입니다.
- 후보 키와 job/assessment ID는 receipt 안의 불투명 공개 식별자입니다.
- 보충 holdout은 같은 6BOY 개발 구조의 fresh-seed 검증이며 formal 14개 기준을 변경하지 않고 새 target·독립 구조·training holdout·통계적 일반화를 입증하지 않습니다.
- 공개 receipt hash는 원본 canonical digest가 아니라 정제된 파일의 hash입니다.
