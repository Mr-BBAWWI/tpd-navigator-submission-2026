실행 안내

먼저 오프라인으로 확인

휴대본 루트의 10_연구비교실_열기.cmd를 실행하면 저장된 비교 자료를 API 호출 없이 열 수 있습니다. 저장 campaign을 다시 렌더링하려면 PowerShell에서 아래 명령을 실행하십시오. 재실행할 때마다 존재하지 않는 새 출력 디렉터리를 선택해야 합니다.

.\runtime\python.exe .\program\scripts\render_research_campaign.py --campaign-dir .\evidence\sprint\campaign-final --output-dir .\my-dashboard

완료 후 .\my-dashboard\index.html을 브라우저로 엽니다.

Live API는 개발자 명시적 선택

기본 실행은 API를 호출하지 않습니다. Live 실행에는 패키지의 assessment와 검증 가능한 parent-export 디렉터리가 필요합니다. parent export는 JSON 파일 하나가 아니라 manifest, job receipt, blobs를 포함한 디렉터리입니다. 키는 PowerShell 환경변수로만 제공하고, 재실행할 때는 .\my-campaign 대신 새로운 디렉터리 이름을 사용하십시오.

$env:DACON_API_KEY="<VALID_DACON_API_KEY>"
.\runtime\python.exe .\program\scripts\run_research_campaign.py --assessment .\evidence\final-reports\raw\assessment.json --parent-export .\evidence\sprint\parent-exports\SMARCA2-9D12-A1A1P --output .\my-campaign --rounds 2 --live-api

Live API는 개발자 opt-in이며, 입력 export 검증 뒤에만 provider를 구성합니다.
